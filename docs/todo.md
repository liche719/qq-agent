**候选做法**（待用户定，别直接做）：加一条——最近 N 分钟内出现 `HTTP 402` / `Insufficient Balance`
就告警。判定要看**官方错误码**（402 或响应里的具体 message），不能靠关键词瞎猜；恢复后要能自动消警
（走现有的 `active`/`sentAt` 机制即可）。数据来源可选：在 `OpenAiCompatStreamingChatModel` 里记进程内
计数器，或让 `AlertNotifier` 扫最近的 WARN 日志。

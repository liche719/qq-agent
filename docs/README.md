## 约定

- **坑号是引用契约**：全项目代码注释和文档都按「坑 38」「坑 52」引用，所以 `pitfalls.md` 的编号
  **只能往后追加，不能重排、不能插号**（当前末条 67）。
- **不要存会腐坏的数字**：表行数、花费、命中率这类快照别写进文档正文；写"去哪看实时数字"。
  真要记，就带明确日期，并说明它的时间窗。
- **不删历史**：被取代的方案标「存档」并写清哪个是现役，不要直接删——很多结论是花时间换来的。

# liche.cloud ICP 备案指南（个人 · 阿里云）

> 用途：给 `liche.cloud`（阿里云大陆 ECS `120.25.170.92`）做 ICP 备案的操作清单。
> 现状：**域名已实名认证、未备案**；`.cloud` 后缀**在工信部批复的可备案清单内**，所以备案可行。
> 备案必须由主体本人操作（证件 + 人脸核验），AI 只能准备资料和后续技术配合。

## 0. 入口

| 用途 | 地址 |
|---|---|
| 阿里云备案控制台（从这里开始） | <https://beian.aliyun.com> |
| 阿里云备案帮助（官方规则） | <https://help.aliyun.com/zh/icp-filing/> |
| 备案服务号资格说明（官方 FAQ） | <https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/server-check-faq> |
| 工信部备案查询（核对结果） | <https://domain.miit.gov.cn> |

## 1. 开工前的硬性条件（先自查，缺一条都会被打回）

1. **服务器必须是包年包月，且剩余时长 ≥ 3 个月**
   - 在哪看：ECS 控制台 → 实例列表 → 该实例的「付费方式」与「到期时间」。
   - **按量付费拿不到备案服务号**，必须先转包年包月（或续费到剩余 ≥3 个月）。
   - 这是最常见的卡点，**先确认这一条再动手**。
2. **域名实名认证已通过，且注册人与备案主体同名**（个人＝身份证同名）。
   - 已完成 ✅（`liche.cloud` 注册人信息与身份证一致）。备案期间**不要**变更域名持有者信息。
3. **手机号**：本人实名手机，能收验证码；同一手机号关联主体数量有限制（用完就得换号）。
4. **应急联系电话**：**必须与主体手机号不同**（填家人号码最稳），否则必被打回。
5. **邮箱**：能正常收信（初审结果、管局通知都发这里）。
6. **阿里云 App**：手机上装好并登录同一账号（人脸核验要用）。
7. **网站信息先想好**（下面第 3 步要填）：
   - 网站名称：个人备案写「某某的个人主页 / 技术笔记」这类，**不能出现公司、集团、商城、官网、平台等词**；
   - 服务内容：选「其他」或「个人空间/博客」类，**个人备案不能选电子商务等经营性内容**；
   - 网站负责人＝本人；一个主体可同时备多个域名。

## 2. 材料清单

- [ ] 身份证原件（正反面拍照，清晰、无反光、四角完整、无遮挡）
- [ ] 本人实名手机号 + 一个不同的应急联系电话
- [ ] 常用邮箱
- [ ] 详细联系地址（精确到门牌号，个人填身份证地址或实际居住地址）
- [ ] 符合条件的那台 ECS 实例（见第 1 条第 1 点）
- [ ] 阿里云 App（人脸核验）

## 3. 逐屏操作

### 步骤 1：申请备案服务号
1. ECS 控制台 → 找到 `120.25.170.92` 那台实例 → **备案服务号**（或在备案控制台里自动关联实例）。
2. 确认实例符合条件后申请，通常每个符合条件的实例可申请 5 个服务号（以控制台显示为准），备案时选用其中一个。

### 步骤 2：提交备案申请（PC 控制台）
1. 打开 <https://beian.aliyun.com> → **开始备案** → 选择「**首次备案**」。
2. **填写主体信息**：个人 → 姓名、身份证号、证件地址（详细到门牌）、手机号、邮箱、应急电话。
3. **填写网站信息**：
   - 域名填 `liche.cloud`（如还想备 `www.liche.cloud` 一并填）；
   - 网站名称、服务内容按第 1 条第 7 点填；
   - 选择关联的 ECS 实例 / 备案服务号；
   - 网站负责人＝本人，联系方式同上。
4. **上传身份证正反面**，按提示拍照要求来（不要翻拍屏幕、不要美颜、边缘完整）。
5. 提交 → 进入阿里云初审。

### 步骤 3：阿里云初审（1~2 个工作日）
- 阿里云会在工作时间**打电话核验**（常见来电 95187 开头），**务必接听**；两次未接可能被驳回，重新排队。
- 初审驳回会在控制台写明原因，按提示改完重新提交即可。

### 步骤 4：人脸核验（初审通过后）
- 收到短信/站内信后，用**阿里云 App** 扫码做人脸识别（现在不用幕布拍照了）。

### 步骤 5：提交管局审核（3~20 个工作日）
- 阿里云把材料提交给你所在省份的通信管理局；多数省份 **3~7 个工作日**，个别省份更慢。
- 期间管局可能电话核验，保持手机畅通。

### 步骤 6：通过之后
- 收到备案号（形如 `京ICP备2026xxxxxx号-1`），在工信部查询系统能查到。
- **法规要求：网站底部展示备案号并链接到 <https://beian.miit.gov.cn>**（我们的面板可以加一行页脚，需要的话我来做）。
- 之后如换服务器、换主体、加域名，需要做**变更/新增备案**；换服务商要做**接入备案**。

## 4. 网站名称与备注怎么写（初审最容易卡的地方）

阿里云对**个人备案的网站名称**有硬性规则（[官方说明](https://developer.aliyun.com/article/1189978)）：

- ≥3 个汉字；不能纯数字、纯英文、用域名充当；不能含特殊符号；
- 必须与实际网站内容一致；**不能用人物名、地名、成语**；
- **全国禁止出现的词汇**：个人空间、爱好者、博客、导航、工作室、论坛、平台、热线、社区、社团、网络、网站、网址、主页、资讯、作品展示 等。

**备案备注**要求不少于 20 字，并具体说明网站开办后的内容（[官方说明](https://developer.aliyun.com/ask/182392)）。

本项目的推荐填法（如实描述 + 个人自用口径，避开禁词）：

| 字段 | 内容 |
|---|---|
| 网站名称 | `技术学习记录`（备选：`开发学习记录`、`个人开发记录`） |
| 网站备注 | `本人个人学习开发使用，用于记录自己的编程学习过程，并查看自己开发的程序运行状态，仅供本人登录使用，不对外开放注册，无任何商品交易、广告等经营性内容。` |

反面例子（会被核验打回）：`个人开发应用的运维监控网站` —— 含禁词「网站」，且「运维监控」易被判为企业/专业服务用途；字数也不足 20 字。

其它注意：
- **名称与备注口径要一致**，否则被判「名称与内容不符」。
- 报错时先点「查看报错详情」看原始原因：若是「域名信息核验不符 / 主体信息不符」，那与名称备注无关，多半是**域名实名信息与身份证不一致**（域名持有者需与备案主体同名）。

## 5. 常见被打回原因（对照避免）

| 原因 | 怎么避 |
|---|---|
| 应急电话与主体手机相同 | 换一个不同的号码 |
| 网站名称含禁用词或与主体无关 | 用「某某的个人主页/技术笔记」 |
| 证件地址不详细 | 写到门牌号 |
| 域名注册人与备案主体不一致 | 备案前别改域名持有者信息 |
| ECS 剩余时长不足 3 个月 / 按量付费 | 先续费或转包年包月 |
| 初审电话没接 | 95187 类来电别拦、别漏 |
| 手机号关联主体过多 | 换一个未用过的手机号 |
| 网站内容与备案信息不符（个人做经营性内容） | 保持个人用途，别出现商品/支付/公司名 |

## 6. 备案期间，这套服务怎么处理（重要）

管局要求**备案通过前不得以该域名对外开通网站**，所以稳妥做法是备案提交后把域名先摘下来：

- **方案 A（推荐）**：**暂停 `A @ → 120.25.170.92` 解析**，面板改用 `https://120.25.170.92/`（证书会提示名称不匹配，点"继续访问"即可）。备案不需要域名能解析。
- **方案 B**：把面板端口临时切回 8443（改 `SERVER_PORT` 再重建容器），域名解析保留。

两个方案都**不影响证书自动续期**——Let's Encrypt 续期用的是 DNS-01，只往域名里加一条临时 TXT 记录，跟 A 记录无关。

备案通过后恢复：重新加回 A 记录（或把端口改回 443），面板回到 `https://liche.cloud/`。
> 这两步我都可以直接用现有的 DNS API 钥匙和服务器权限帮你做，一条命令的事。

## 7. 时间线预期

| 阶段 | 耗时 |
|---|---|
| 准备材料 + 提交 | 你自己 1~2 小时 |
| 阿里云初审 | 1~2 个工作日 |
| 人脸核验 | 几分钟 |
| 管局审核 | 3~20 个工作日（多数 3~7 天） |
| **合计** | **通常 4~10 天** |

## 8. 不想备案的替代方案

- **把服务迁到境外/香港服务器**（境外无需 ICP 备案）：代价是迁数据、重配证书与环境，且延迟略增。
- **维持现状**：443 上未备案域名目前实际可访问（阿里云拦得住的是 80 端口 HTTP，443 有加密一般拦不住），属于"灰色可用"，被抽查到通常先通知整改。
